# Omni Code

**Web 版 AI Agent / IDE** — Claude Code 相当が、自分のマシンで動く。

> 🌐 **他の言語で読む：** [English](README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一言で指示すれば、AI があとは全部やる：ファイルの読み書き、コード検索、
コマンド実行、画像素材の生成 — この IDE 自体の操作まで。見ているだけで終わる。

> ⭐ **セルフ改善 —— Omni Code を別物にする機能。**
> Omni Code は**自分自身のソースコードを修正できる**。**セルフ改善モード**に切り替え、
> 気になる点や欲しいものを伝えるだけ（「ファイルツリーをドラッグ移動対応に」、
> 「トークンメーターが重い」）。調査・修正・検証のうえ、変更をバージョン履歴に記録
> —— *いま読んでいるこのドキュメントも、使っているこの機能も、
> こうして生まれた*。詳しくは下の [§ セルフ改善](#-セルフ改善--自分で育つツール)へ。
> 標準搭載。他のローカル coding agent にはない。

## クイックスタート

### 1. 動作環境

- **XAMPP（PHP 8.2 + Apache）**、`curl` / `json` / `mbstring` / `openssl`
  の4拡張のみ —— composer 不要、ビルド不要、bundler 不要
- いずれかの **Claude / OpenAI / Gemini / OpenRouter** API キー（既定ではブラウザの localStorage のみ保存）

### 2. インストール

1. このフォルダを `D:/xampp/htdocs/app/OmniCode` にコピー（htdocs 配下ならどこでも可）
2. XAMPP コントロールパネルで Apache を起動
3. ブラウザで `http://localhost/app/OmniCode/app/` を開く
4. 求められたら API キーを貼る（右上の鍵アイコン）—— **開発には Claude 推奨**

`npm install` 不要。ビルド不要。フロントは素の `<script>`、バックエンドはゼロFWの PHP。

### 3. 表示言語

**設定**パネル上部の言語ドロップダウンで **English / 繁體中文 / 简体中文 / 日本語 / 한국어**
に即時切替。既定は英語；設定は `data/config.json` に保存され、初回描画前に適用（チラつきなし）。

## 🚀 セルフ改善 —— 自分で育つツール

> 他の agent は**あなたの**プロジェクトを作る。Omni Code は **Omni Code 自体**を作り直せる。

チャットヘッダの**セルフ改善ボタン**（または `Ctrl+Shift+S`）で、
ワークスペースが Omni Code 本体のソースに切り替わる。あとは話すだけ：

- 「設定パネルがダサい、モデルパネル風に作り直して」
- 「新しいダイアログに日本語訳をつけて」
- 「ターミナル出力の読み取りに race condition がある、探して」

裏側で起きていること：

1. **限定ワークスペース** —— Agent のファイル権限は Omni Code 本体に固定、
   プロジェクトと同じ安全境界で動く。
2. **履歴とバージョン**（`data/selfimprove/state.json`）—— 完了ごとに記録：
   タイトル・概要・変更ファイル・semver 上げ（`patch` 修正、`minor` 新機能、
   `major` 構成変更）。モデルが記録し忘れたらシステムが自動補記。
3. **ロードマップ** —— 先の仕事はバージョン項目に（`v1.0.0：…`）。「X を roadmap に」
   と言えばセッションをまたいで残り、完了時に `roadmapItem` で自動チェック。
4. **セルフパネル** —— ボタンで履歴・計画ビューアも開く：どのバージョンで何が変わり、
   どの対話が産んだか（ワンクリックでその対話に戻れる）。

この README の多言語版も、設定パネルの作り直しも、5言語辞書自体も ——
全部 Omni Code が Omni Code の中でこうして作った。

## 基本概念

### ワークスペース —— 唯一のファイル安全境界

**ワークスペースはディスク上の任意フォルダでよい**、Omni Code 配下でなくてよい。切替は3通り：

1. トップバーのフォルダパスをクリック → 参照 or パス直貼り
2. ターミナルでワークスペース外に `cd` →「ここに切替」ボタンが出る
3. サイドバー「設定 → ワークスペースを変更」

> **単一プロジェクトのフォルダを選ぶこと。`htdocs` やドライブ全体は NG。**
> ワークスペースは検索とファイルツリーの範囲：数十万ファイルの目录を選ぶと、
> 全体検索がタイムアウトで部分結果になる（明示はされるが体験が悪い）。
> 既定は Omni Code 自体のフォルダ —— 試し場にどうぞ。

**なぜワークスペースが必要か？** Omni Code 唯一のファイル安全境界だから。
Agent はワークスペース内に100%権限（作成／削除／変更／移動）、
外のパスはバックエンドが拒否。プロジェクトを変える＝ワークスペースを変える、一度に1範囲。

### はじめる

右の入力欄に一言：

- 「このプロジェクトの構成を見て」
- 「app/js のログイン検証に境界バグがある、直してテストも足して」

`/` はスラッシュコマンド（`/doctor` ヘルスチェック、`/compact` 圧縮、
`/forget <名前>` 記憶削除…）。`@` でファイル言及、`Shift+Tab` で権限モード循環。

### Mode —— 実行前にどれだけ聞くか

| モード | 意味 |
|---|---|
| 📋 計画 | 調査のみ：読取・検索可、書込・コマンド不可 |
| ● 手動 | 書込・コマンド実行前に確認（最も安全な日常モード） |
| ✏️ 自動編集 | ファイル作成／変更／削除は確認不要；コマンドは確認 |
| 🚀 全自動 | 100%：全ファイル操作・コマンド・ネットを自動承認 |

安全境界は常に有効：ワークスペース内のみ、ローカル接続のみ。

### Effort —— 推論強度

Claude Code と同名（`off` → `max`）。推論は token を消費するが最終回答には出ない。
モデル毎の上限は自動尊重、無理強いしない。

## 安全

- サービスは `127.0.0.1` のみ受付、それ以外は 403
- Agent のファイル権限は選択ワークスペースに厳密限定、逃避はバックエンドが拒否
- API 中継はドメインホワイトリスト —— オープンプロキシにならない
- API キーは既定でブラウザ localStorage のみ

**公開ネットに晒さないこと。** ローカルファイルへの完全権限を前提に設計されている。
