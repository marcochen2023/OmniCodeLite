# Omni Code

**网页版 AI Agent / IDE** — 对标 Claude Code，在你自己的电脑上运行。

> 🌐 **其他语言：** [English](README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

说一句话，AI 就自动判断该做什么：读写文件、搜索代码、执行命令、生成图片素材、
甚至直接操作这个 IDE 的界面本身。你只要看着它做完。

> ⭐ **自我提升 —— Omni Code 与众不同的关键功能。**
> Omni Code 可以修改**它自己的源代码**。切到**自我提升模式**，直接告诉它哪里不好、
> 想要什么（"文件树支持拖拽移动"、"token 表有点卡"），它会自己调查、改程序、
> 跑验证，再把这次改动记进版本历程 —— *你现在读的这份文档、用的这个功能，
> 就是它自己这样做出来的*。详见下方 [§ 自我提升](#-自我提升--会自己长大的工具)。
> 开箱即有，别家本地 coding agent 没有。

## 快速开始

### 1. 环境需求

- **XAMPP（PHP 8.2 + Apache）**，只需要 `curl` / `json` / `mbstring` / `openssl`
  四个扩展 —— 不用 composer、不用构建、不用 bundler
- 任一家 **Claude / OpenAI / Gemini / OpenRouter** API Key（默认只存在你的浏览器 localStorage）

### 2. 安装

1. 把这个文件夹复制到 `D:/xampp/htdocs/app/OmniCode`（htdocs 下任何位置都可以）
2. 打开 XAMPP 控制面板，启动 Apache
3. 浏览器打开 `http://localhost/app/OmniCode/app/`
4. 被问到时粘贴 API Key（右上角钥匙图标）—— **写程序建议用 Claude**

不用 `npm install`。不用构建。前端是传统 `<script>`，后端是零框架 PHP。

### 3. 界面语言

**设置**面板顶部可切 **English / 繁體中文 / 简体中文 / 日本語 / 한국어**，
整个界面即时切换。默认英文；偏好存在 `data/config.json`，开机第一帧就套用（不闪烁）。

## 🚀 自我提升 —— 会自己长大的工具

> 别家 agent 帮你做**你的**项目。Omni Code 还能重做 **Omni Code 自己**。

点对话栏标头的**自我提升按钮**（或 `Ctrl+Shift+S`），工作区就会切到 Omni Code
自己的源码。接下来用说的就好：

- "设置面板有点丑，照模型面板的样子重做"
- "新的对话框补一下日文翻译"
- "终端输出读取那边有 race condition，找出来"

背后发生了什么：

1. **限定的工作区** —— Agent 的文件权限被钉在 Omni Code 安装目录，
   跟项目工作区走同一套安全边界。
2. **历程与版本**（`data/selfimprove/state.json`）—— 每次改完都记一笔：
   标题、摘要、动了哪些文件、版本推进（`patch` 修 bug、`minor` 新功能、
   `major` 架构变动）。模型忘了记，系统会兜底补一笔。
3. **版本规划** —— 未来的事排成版本项目（`v1.0.0：…`）。说"把 X 排进 roadmap"，
   跨会话都留着；做完带 `roadmapItem` 结账，自动打勾。
4. **自我提升面板** —— 按钮同时打开历程与规划查看器：看过哪些版本、改了什么、
   是哪次对话产生的（一键跳回那次对话）。

这份 README 的多语言版本、设置面板的重做、五语言字典本身 —— 全部是 Omni Code
在 Omni Code 里面自己做出来的。

## 核心概念

### 工作区 —— 唯一的文件安全边界

**工作区可以是硬盘上任何文件夹**，不限于 Omni Code 底下。三种切换方式：

1. 点顶栏的文件夹路径 → 浏览或直接粘贴路径
2. 在终端机 `cd` 到工作区外的文件夹 → 会跳出"切换到这里"按钮
3. 侧栏"设置 → 变更工作区"

> **请选"单一项目"的文件夹，不要选 `htdocs` 或整颗磁盘。**
> 工作区是搜索与文件树的范围：选一个有几十万个文件的目录，
> 全局搜索会扫到超时而只返回部分结果（会明确告诉你，但体验很差）。
> 默认工作区是 Omni Code 自己的文件夹，可以先拿它试玩。

**为什么要有工作区这个概念？** 它是 Omni Code 唯一的文件安全边界。
Agent 在工作区内有 100% 权限（新增／删除／修改／移动），
工作区外的路径后端一律拒绝。换项目就换工作区，一次只开放一个范围。

### 开始

在右侧输入框打任何一句话：

- "帮我看看这个项目的结构"
- "app/js 的登录验证有边界问题，修掉并补测试"

`/` 开头是斜线指令（`/doctor` 健康检查、`/compact` 压缩上下文、
`/forget <名称>` 删记忆…）。`@` 提及文件，`Shift+Tab` 循环切换权限模式。

### Mode —— 动手前问多少

| 模式 | 意义 |
|---|---|
| 📋 规划 | 只调查不动手：可读档、搜索，不可写入或执行命令 |
| ● 手动 | 写档与执行命令前会问你（最安全的日常模式） |
| ✏️ 自动编辑 | 文件新增／修改／删除免问；命令仍要问 |
| 🚀 全自动 | 100%：工作区内文件、命令、网络全部自动放行 |

安全边界永远在：只能碰工作区内的文件，只接受本机连接。

### Effort —— 推理强度

等级名称同 Claude Code（`off` → `max`）。推理会花 token，但不会出现在最终回复。
各模型的上限会自动尊重，不会硬上。

## 安全

- 服务只接受来自 `127.0.0.1` 的连接，其他来源一律 403
- Agent 的文件权限严格限制在你选定的工作区内，路径逃逸会被后端拒绝
- API 中继有域名白名单，不会变成开放代理
- API 密钥默认只存在浏览器 localStorage

**请勿把这个服务暴露到公开网络。** 它被设计成对本机文件有完整权限。
