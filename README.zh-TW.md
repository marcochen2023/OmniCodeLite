**網頁版 AI Agent / IDE** — 對標 Claude Code，在你自己的電腦上執行。

> 🌐 **其他語言：** [English](README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

打一句話，AI 就自動判斷該做什麼：讀寫檔案、搜尋程式碼、執行命令、生成圖片素材、
甚至直接操作這個 IDE 的介面本身。你只要看著它做完。

> ⭐ **自我提升 —— Omni Code 與眾不同的關鍵功能。**
> Omni Code 可以修改**它自己的原始碼**。切到**自我提升模式**，直接告訴它哪裡不好、
> 想要什麼（「檔案樹支援拖曳搬移」、「token 錶有點卡」），它會自己調查、改程式、
> 跑驗證，再把這次改動記進版本歷程 —— *你現在讀的這份文件、用的這個功能，
> 就是它自己這樣做出來的*。詳見下方 [§ 自我提升](#-自我提升--會自己長大的工具)。
> 開箱即有，別家本地 coding agent 沒有。

## 快速開始

### 1. 環境需求

- **XAMPP（PHP 8.2 + Apache）**，只需要 `curl` / `json` / `mbstring` / `openssl`
  四個擴充 —— 不用 composer、不用建置、不用 bundler
- 任一家 **Claude / OpenAI / Gemini / OpenRouter** API Key（預設只存在你的瀏覽器 localStorage）

### 2. 安裝

1. 把這個資料夾複製到 `D:/xampp/htdocs/app/OmniCode`（htdocs 下任何位置都可以）
2. 打開 XAMPP 控制面板，啟動 Apache
3. 瀏覽器開 `http://localhost/app/OmniCode/app/`
4. 被問到時貼上 API Key（右上角鑰匙圖示）—— **寫程式建議用 Claude**

不用 `npm install`。不用建置。前端是傳統 `<script>`，後端是零框架 PHP。

### 3. 介面語言

**設定**面板頂部可切 **English / 繁體中文 / 简体中文 / 日本語 / 한국어**，
整個介面即時切換。預設英文；偏好存在 `data/config.json`，開機第一幀就套用（不閃爍）。

## 🚀 自我提升 —— 會自己長大的工具

> 別家 agent 幫你做**你的**專案。Omni Code 還能重做 **Omni Code 自己**。

點對話欄標頭的**自我提升按鈕**（或 `Ctrl+Shift+S`），工作區就會切到 Omni Code
自己的原始碼。接下來用說的就好：

- 「設定面板有點醜，照模型面板的樣子重做」
- 「新的對話框補一下日文翻譯」
- 「終端機輸出讀取那邊有 race condition，找出來」

背後發生了什麼：

1. **限定的工作區** —— Agent 的檔案權限被釘在 Omni Code 安裝目錄，
   跟專案工作區走同一套安全邊界。
2. **歷程與版本**（`data/selfimprove/state.json`）—— 每次改完都記一筆：
   標題、摘要、動了哪些檔、版本推進（`patch` 修 bug、`minor` 新功能、
   `major` 架構變動）。模型忘了記，系統會兜底補一筆。
3. **版本規劃** —— 未來的事排成版本項目（`v1.0.0：…`）。說「把 X 排進 roadmap」，
   跨會話都留著；做完帶 `roadmapItem` 結帳，自動打勾。
4. **自我提升面板** —— 按鈕同時打開歷程與規劃檢視器：看過哪些版本、改了什麼、
   是哪次對話產生的（一鍵跳回那次對話）。

這份 README 的多語系版本、設定面板的重做、五語系字典本身 —— 全部是 Omni Code
在 Omni Code 裡面自己做出來的。

## 核心概念

### 工作區 —— 唯一的檔案安全邊界

**工作區可以是硬碟上任何資料夾**，不限於 Omni Code 底下。三種切換方式：

1. 點頂列的資料夾路徑 → 瀏覽或直接貼上路徑
2. 在終端機 `cd` 到工作區外的資料夾 → 會跳出「切換到這裡」按鈕
3. 側欄「設定 → 變更工作區」

> **請選「單一專案」的資料夾，不要選 `htdocs` 或整顆磁碟。**
> 工作區是搜尋與檔案樹的範圍：選一個有幾十萬個檔案的目錄，
> 全域搜尋會掃到超時而只回傳部分結果（會明確告訴你，但體驗很差）。
> 預設工作區是 Omni Code 自己的資料夾，可以先拿它試玩。

**為什麼要有工作區這個概念？** 它是 Omni Code 唯一的檔案安全邊界。
Agent 在工作區內有 100% 權限（新增／刪除／修改／移動），
工作區外的路徑後端一律拒絕。換專案就換工作區，一次只開放一個範圍。

### 開始

在右側輸入框打任何一句話：

- 「幫我看看這個專案的結構」
- 「app/js 的登入驗證有邊界問題，修掉並補測試」

`/` 開頭是斜線指令（`/doctor` 健康檢查、`/compact` 壓縮上下文、
`/forget <名稱>` 刪記憶…）。`@` 提及檔案，`Shift+Tab` 循環切換權限模式。

### Mode —— 動手前問多少

| 模式 | 意義 |
|---|---|
| 📋 規劃 | 只調查不動手：可讀檔、搜尋，不可寫入或執行命令 |
| ● 手動 | 寫檔與執行命令前會問你（最安全的日常模式） |
| ✏️ 自動編輯 | 檔案新增／修改／刪除免問；命令仍要問 |
| 🚀 全自動 | 100%：工作區內檔案、命令、網路全部自動放行 |

安全邊界永遠在：只能碰工作區內的檔案，只接受本機連線。

### Effort —— 推理強度

等級名稱同 Claude Code（`off` → `max`）。推理會花 token，但不會出現在最終回覆。
各模型的上限會自動尊重，不會硬上。

## 安全

- 服務只接受來自 `127.0.0.1` 的連線，其他來源一律 403
- Agent 的檔案權限嚴格限制在你選定的工作區內，路徑逃逸會被後端拒絕
- API 中繼有網域白名單，不會變成開放代理
- API 金鑰預設只存在瀏覽器 localStorage

**請勿把這個服務暴露到公開網路。** 它被設計成對本機檔案有完整權限。
